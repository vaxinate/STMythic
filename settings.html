Mythic Oracle

Oracle nudge

Reminds the narrator to consult the oracle after this many replies without calling mythic_fate or mythic_table. Player rolls, scene checks and chaos changes don't reset the count.
Nudge text
\{{count}} is the number of replies; ST macros like \{{user}} work too.

Fate tool description

What the narrator is told about mythic_fate.

Meaning tables

One per line: Name | when to use. These generate the mythic_table tool.

Table tool description

\{{tables}} is replaced with - Name: when to use for each table.
